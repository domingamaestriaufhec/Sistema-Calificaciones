# Sistema de Gestión de Calificaciones

## Descripción
Este proyecto es una aplicación de consola desarrollada en Python que ilustra el manejo y la manipulación de **arreglos y vectores (listas)** para el control y análisis académico de un grupo de estudiantes. Permite realizar operaciones esenciales como almacenamiento, recorrido, modificación por índices, cálculos estadísticos y filtros condicionales.

## Objetivo
Aplicar los conceptos fundamentales de estructuras de datos lineales (arreglos o vectores), demostrando el acceso mediante índices, iteraciones con ciclos, evaluación condicional con `if`, algoritmos de búsqueda y operaciones de agregación numérica en Python.

## Lenguaje Utilizado
- **Python 3.x**

## Funcionalidades Desarrolladas
1. **Vector de Datos:** Inicialización de un vector con 5 calificaciones numéricas (`[85, 67, 92, 74, 58]`).
2. **Visualización y Recorrido:** Recorrido del vector utilizando ciclos `for` para mostrar la posición (índice), el valor de la calificación y el estado (Aprobado / Reprobado).
3. **Acceso por Índices:** Consulta directa del elemento ubicado en cualquier índice especificado por el usuario.
4. **Modificación de Elementos:** Actualización del valor de una calificación en una posición determinada mediante asignación directa por índice.
5. **Cálculos Estadísticos:**
   - Cálculo del promedio general de las calificaciones.
   - Búsqueda de la calificación más alta y más baja con sus respectivos índices.
   - Conteo y porcentaje de estudiantes aprobados (nota $\ge$ 70) y reprobados (nota $<$ 70) usando condicionales `if`.
6. **Búsqueda:** Búsqueda secuencial de calificaciones específicas en el vector.
7. **Menú Interactivo:** Interfaz por línea de comandos para facilitar la navegación del usuario.

## Instrucciones para Ejecutar el Programa

### Prerrequisitos
- Tener instalado **Python 3.8** o superior en su sistema. Para verificarlo, ejecute en su terminal:
  ```bash
  python --version
  ```

### Pasos de ejecución
1. Clonar el repositorio o descargar los archivos del proyecto:
   ```bash
   git clone https://github.com/TU_USUARIO/sistema-calificaciones.git
   ```
2. Acceder al directorio del proyecto:
   ```bash
   cd "pf itla"
   ```
3. Ejecutar el archivo principal:
   ```bash
   python main.py
   ```
